# Mリーグポイント集計ページ

[ドラフト会議プロジェクト](https://github.com/Ushibays1992-HUB-Claude/mleague-draft)で確定した指名結果をもとに、
Mリーグ公式サイト（https://m-league.jp/stats）から現シーズン（2026-27レギュラーシーズン）のポイントを毎日13:17に
自動スクレイピングし、参加者5名（うし・犬丼・ちんさん・木村・ヤンマ）ごとの合計ポイントと順位変動を表示する静的サイト。

## 集計内容

1. **選手指名ポイント** — 各参加者が選手ドラフトで指名した4名の合計ポイント
2. **チーム指名ポイント** — 各参加者がチームドラフトで指名したMリーグ本チーム所属選手4名の合計ポイント
   （公式の「累積ポイント」ページはJS+署名付きAPIで直接取得できないため、`/stats`の選手個人ポイントを
   チーム内で合算して算出している）

## 構成

- `scripts/scrape.py` — GitHub Actionsから毎日実行。`/stats`をスクレイピングし、`data/history.json`に
  前日から変化があった日だけレコードを追記する
- `data/draft_results.json` — 参加者⇔選手/チームの対応表（ドラフト会議プロジェクトから複製）
- `data/history.json` — 日次スナップショットの履歴（自動更新）
- `index.html` / `style.css` / `app.js` — 集計結果と順位変動グラフを表示する静的ページ

## 自動停止

レギュラーシーズンは2027-03-02まで（結果は翌日昼までに反映想定）のため、
`scrape.py`は2027-03-03を過ぎると何もせず終了する。
